# Быстрый старт

## Онлайн-конвертер Guitar Pro

После включения GitHub Pages (Settings → Pages → Build and deployment → GitHub Actions) конвертер будет доступен по адресу [https://dm5xia9.github.io/freakrating-dj/](https://dm5xia9.github.io/freakrating-dj/). Workflow публикует сайт автоматически при изменениях страницы или конвертера в `main`.

Выбери `.gp`, `.gp3`, `.gp4`, `.gp5`, `.gpx` или `.gtp`, нажми **Конвертировать в JSON** и сохрани скачанный файл. Обработка происходит в браузере; исходный Guitar Pro файл не отправляется на GitHub. JSON содержит `title`, `bpm`, `maxVoices` и массив событий `score` с полями `at`, `dur`, `notes`.

## Tampermonkey: выбор песни в игре

Tampermonkey — расширение для браузера, которое запускает скрипт на странице игры. Оно добавляет HUD в левом нижнем углу: проигрыватель и ящик с пластинками, который выезжает, когда подводишь курсор к углу. Скрипт загружает HUD, проигрыватель и список песен с GitHub, поэтому нужен доступ к интернету.

1. Установи расширение Tampermonkey для своего браузера.
2. Открой [скрипт FreakRating DJ](https://raw.githubusercontent.com/Dm5Xia9/freakrating-dj/main/tampermonkey/freakrating-player.user.js) и нажми **Install** в открывшейся вкладке Tampermonkey.
3. Открой FreakRating и войди в игровой мир. **Ё** (`` ` ``) освобождает курсор без паузы, чтобы нажимать на HUD.

- **Пластинки** играют музыку: гитарные песни звучат через синтезатор, свои GP-файлы конвертируются в браузере, WAV/mp3 и YouTube тоже можно добавить (Ctrl+V или перетаскиванием на HUD).
- **Ноты** доступны, пока сидишь за гитарой: лист ставится на пюпитр, и песня играется на игровой гитаре.
- **Громкоговоритель** включает трансляцию в голосовой чат игры: гитарные пластинки и свои файлы подмешиваются к твоему микрофону. Нужен включённый голосовой чат; для музыки лучше режим голоса «по кнопке» — HUD сам держит рацию, пока играет трек. YouTube при включённой трансляции открывается в маленьком отдельном окне: браузер один раз спросит, звук какой вкладки захватить, — выбери окно YouTube и включи «Поделиться звуком». В клиенте FreakRating YouTube идёт через его радио (yt-dlp), без окна. Ссылки на чужие аудиофайлы браузер захватить не даёт, они слышны только тебе. Тумблер микрофона выключает твой голос: тогда другие слышат только музыку.

Скрипт настроен для сайта [freakrating.lol](https://freakrating.lol/). Песни доступны как постоянные URL вида `https://raw.githubusercontent.com/Dm5Xia9/freakrating-dj/main/lib/play-outkast-hey-ya.js`.

## Релизы

При публикации тега `v*` GitHub Actions автоматически собирает ZIP с проигрывателем, песнями и Tampermonkey-скриптом и прикладывает его к GitHub Release. Например:

```sh
git tag v1.0.0
git push origin v1.0.0
```

Для использования отдельных треков без ZIP доступны постоянные Raw URL выше; обновления `main` сразу становятся видны плееру.

Запустить песню можно прямо в браузере. Для этого ничего устанавливать не нужно.

## Как включить песню

1. Открой FreakRating в Chrome, войди в игровой мир, перейди в локацию **«Лес»** и сядь за гитару. Проигрывание начнётся, когда ты будешь за ней.
2. В этой папке открой файл `src/guitar-player.js`, скопируй его целиком.
3. Вернись в окно игры, открой инструменты разработчика клавишей **F12** и выбери вкладку **Console**.
4. Вставь скопированный текст и нажми **Enter**. В консоли должно появиться сообщение, что проигрыватель готов.
5. Открой папку `lib` и выбери песню с названием, начинающимся на `play-`.
6. Скопируй содержимое файла целиком, вставь в ту же консоль и нажми **Enter**.

Чтобы сыграть другую песню, вставь в консоль содержимое другого файла `play-...js`. Чтобы остановить музыку, введи `window.guitarPlayer.stop()` и нажми **Enter**.

Если консоль не принимает вставку и показывает предупреждение, прочитай его и введи указанную браузером фразу подтверждения, затем повтори вставку.

## Новые песни: быстрый старт конвертации

1. Скопируй файл табулатуры (`.gp`, `.gp3`, `.gp4`, `.gp5`, `.gpx` или `.gtp`) в `lib/sources/`.
2. Открой **Терминал**. При первом использовании установи нужные компоненты:

   ```sh
   npm install
   ```

3. Запусти конвертацию, подставив имя своего файла:

   ```sh
   npm run convert -- "lib/sources/имя-файла.gp5"
   ```

4. Новый файл `play-...js` появится в `lib/`. Включи песню по шагам из раздела **«Как включить песню»**.
