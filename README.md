# Быстрый старт

Запустить песню можно прямо в браузере. Для этого ничего устанавливать не нужно.

## Как включить песню

1. Открой FreakRating в Chrome, войди в игровой мир, перейди в локацию **«Лес»** и сядь за гитару. Проигрывание начнётся, когда ты будешь за ней.
2. В этой папке открой файл `src/guitar-player.js`, скопируй его целиком.
3. Вернись в окно игры, открой инструменты разработчика клавишей **F12** и выбери вкладку **Console**.
4. Вставь скопированный текст и нажми **Enter**. В консоли должно появиться сообщение, что проигрыватель готов.
5. Открой папку `lib` и выбери песню с названием, начинающимся на `play-`.
6. Скопируй содержимое файла целиком, вставь в ту же консоль и нажми **Enter**.

Чтобы сыграть другую песню, вставь в консоль содержимое другого файла `play-...js`. Чтобы остановить музыку, введи `window.guitarPlayer.stop()` и нажми **Enter**.

Если консоль не принимает вставку и показывает предупреждение, прочитай его и введи указанную браузером фразу подтверждения, затем повтори вставку.

## Новые песни: быстрый старт конвертации

1. Скопируй файл табулатуры (`.gp`, `.gp3`, `.gp4`, `.gp5`, `.gpx` или `.gtp`) в `lib/sources/`.
2. Открой **Терминал**. При первом использовании установи нужные компоненты:

   ```sh
   npm install
   ```

3. Запусти конвертацию, подставив имя своего файла:

   ```sh
   npm run convert -- "lib/sources/имя-файла.gp5"
   ```

4. Новый файл `play-...js` появится в `lib/`. Включи песню по шагам из раздела **«Как включить песню»**.
